# Nursery Shopping Application

Welcome to the ** Nursery** front-end shopping application! This React-based app allows users to browse a variety of houseplants, add them to a shopping cart, adjust quantities, and view their total purchase before checkout.

## Project Overview

Nursery Shopping App is an online storefront for houseplant enthusiasts. The app offers a smooth shopping experience with three main pages:

- **Landing Page:** Introduction to the company with a background image and navigation.  
- **Product Listing Page:** Browse houseplants organized by categories and add them to the shopping cart.  
- **Shopping Cart Page:** Review cart items, modify quantities, remove items, and view totals.

---

## Features

- Responsive multi-page interface using React Router  
- Dynamic shopping cart with real-time item count updates  
- Add, remove, increase, and decrease quantities of products in cart  
- Product categories and detailed plant information  
- Intuitive navigation with clear calls-to-action  
- Styled with CSS for a clean and engaging user experience
